# Idealy - Brand Guidelines

## Brand Identity

**Idealy** is an AI-powered product development platform that helps entrepreneurs and developers turn problems into products.

## Logo

### Primary Logo
- File: `/public/idealy-logo.svg`
- Usage: Main branding, headers, marketing materials

### Icon
- File: `/public/icon.svg`
- Usage: Favicon, app icons, small spaces

### Logo Concept
The Idealy logo combines:
- **Light bulb**: Represents ideas and innovation
- **Code brackets**: Represents development and coding
- **Spark**: Represents the "aha!" moment of discovery

## Typography

### Font Family
- **Primary**: System UI fonts (system-ui, -apple-system, sans-serif)
- **Monospace**: Geist Mono (for code)

### Font Sizes
- **Heading 1**: 3rem (48px) - Landing page hero
- **Heading 2**: 2rem (32px) - Section headers
- **Heading 3**: 1.5rem (24px) - Card titles
- **Body**: 1rem (16px) - Regular text
- **Small**: 0.875rem (14px) - Captions

### Font Weights
- **Bold**: 700 - Headings, important text
- **Semibold**: 600 - Subheadings
- **Regular**: 400 - Body text

## Voice & Tone

### Brand Voice
- **Innovative**: We're at the cutting edge of AI-powered development
- **Empowering**: We help developers and entrepreneurs succeed
- **Accessible**: Complex technology made simple
- **Supportive**: We're here to help you build

### Tone Guidelines
- **Professional** but not corporate
- **Friendly** but not casual
- **Confident** but not arrogant
- **Clear** but not simplistic

### Writing Style
- Use active voice
- Keep sentences concise
- Avoid jargon when possible
- Use "we" and "you" to be conversational
- Focus on benefits, not just features

## Messaging

### Tagline
"From Problem to Product in Minutes"

### Value Propositions
1. **Discover Real Problems**: Find validated problems from online communities
2. **AI-Powered Blueprints**: Get complete product plans generated by AI
3. **Full Web IDE**: Build and edit code directly in your browser
4. **AI Code Assistant**: Get help writing, refactoring, and debugging code

### Key Messages
- "Turn community problems into products"
- "AI-powered product development"
- "From idea to code in minutes"
- "Build products faster with AI"

## Visual Style

### Design Principles
1. **Clean & Modern**: Minimal clutter, focus on content
2. **Gradient Accents**: Use gradients sparingly for emphasis
3. **Rounded Corners**: Soft, approachable feel (8px border radius)
4. **Shadows**: Subtle shadows for depth
5. **Whitespace**: Generous spacing for readability

### UI Components
- **Buttons**: Rounded, gradient on primary actions
- **Cards**: White background, subtle shadow, rounded corners
- **Inputs**: Clean borders, focus states with ring
- **Icons**: Lucide icons for consistency

### Imagery
- **Style**: Modern, clean, tech-focused
- **Colors**: Match brand palette
- **Subjects**: Code, developers, innovation, collaboration

## Usage Guidelines

### Do's ✅
- Use the official logo files
- Maintain proper spacing around logo
- Use approved color palette
- Keep messaging consistent
- Use high-quality images

### Don'ts ❌
- Don't distort or rotate the logo
- Don't use unapproved colors
- Don't add effects to the logo
- Don't use low-resolution assets
- Don't mention competitor names

## Social Media

### Profile Images
- Use icon.svg for profile pictures
- Maintain consistent branding across platforms

### Cover Images
- Use gradient background with logo
- Include tagline: "From Problem to Product in Minutes"

### Post Guidelines
- Use brand colors in graphics
- Include logo on promotional images
- Maintain professional tone
- Focus on value and benefits

## Marketing Materials

### Website
- Hero section with clear value proposition
- Feature highlights with icons
- Social proof (testimonials, stats)
- Clear call-to-action buttons

### Documentation
- Consistent header with logo
- Clear navigation
- Code examples with syntax highlighting
- Screenshots with annotations

### Presentations
- Title slide with logo and tagline
- Consistent color scheme
- Minimal text, focus on visuals
- End with call-to-action
